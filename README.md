# 矢量图形编辑器

一个基于 PyQt5 的功能丰富的矢量图形编辑器，参考 Word/PPT 的绘图工具设计。

## 功能特性

### 基础功能
- **图形基础操作**：选择、移动、复制、粘贴、删除
- **多选和框选**：支持便捷的图形选择操作
- **几何变换**：平移、旋转、缩放、对称翻转
- **图形裁剪**：支持部分图形的裁剪功能
- **数据持久化**：保存和加载图形文件，支持二次编辑

### 扩展功能
- **基本图元**：直线、矩形、椭圆、多边形、折线、曲线
- **样式设置**：线条颜色、粗细、填充色等
- **专用图元库**：
  - 流程图符号（开始/结束、判断、处理、输入/输出）
  - 组织结构图符号（矩形框、连接线）
  - 电路图符号（电源、电阻、开关等）
- **连接线功能**：直线、折线、贝塞尔曲线，支持自动吸附
